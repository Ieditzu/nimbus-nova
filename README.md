# nimbus-nova

Nimbus Nova is the middleman for a short task: one side posts it, the other side applies, and both meet only through the platform. The announced VNU Hack challenge is "man in the middle", in the Uber / eMAG sense. The shared contract is in the plan and fixtures; the API is not in this repo yet.
