## Timetable (Bucharest local time, indicative)

- Sun 4 Oct: 09:00-10:00 check-in; 11:30-12:00 specific theme briefing; **12:00 official project start**; 16:00 checkpoint; **18:00 leave venue**. Work may continue off-site overnight under the rules; for minors, parent/guardian is responsible during closure.
- Mon 5 Oct: 09:00 return; 10:00 check-in closes; **11:00 stop starting features**; **11:30 code freeze** (only submission docs and pitch prep may change); **12:00 submission deadline**; 12:00-14:00 jury at stands; 14:30-17:00 finalists pitch on stage; 17:00-17:30 results. All six should be back before check-in closes and present for judging. See V.1-5.4 and VII.

## How judging works

Round 1 is 100 points: problem and relevance **20** (clarity 7, relevance 7, user insight 6); innovation **20** (originality 8, differentiation 6, relation to specific theme 6); technical feasibility **20** (working prototype 8, architecture 6, realism 6); impact and scalability **15** (beneficiaries 5, scale 5, sustainability 5); validation/research **10** (sources 4, feedback 3, assumptions 3); pitch/demo **15** (clarity 5, live demo 5, Q&A 5). Ten teams reach the final; the final uses the same rubric, and only the final-round score determines places 1-3 (VI-VII). A broad feature list is worth less than a reliable demo, credible validation, and explicit theme fit.

## Event-day decisions

1. Ask a team member to record the challenge verbatim and the start/freeze/submission instructions from the briefing. If the challenge does not fit short-job matching, pivot the concept **before** implementing. This document is a conditional planning note, not a completed hackathon deliverable.
2. Record any organizer clarification on prior planning/reusable generic assets, permitted project tools and submission format. Organizers decide unaddressed event-day questions (XIII).
3. Freeze the actual code/features at 11:30 on 5 Oct, including fixes; only edit the submission description and presentation thereafter. Submit by 12:00. Show up as a full team to both rounds if called.
